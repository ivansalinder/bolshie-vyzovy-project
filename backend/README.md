# ReadCheck — Backend API

Серверная часть веб-платформы скрининг-теста для оценки навыков чтения (сценарии для родителей и специалистов, профили детей, расчёт метрик и сохранение сырых данных для дальнейшей аналитики).

## Что уже реализовано

- **Структура проекта и БД (`models.py`, `database.py`, `schemas.py`):**
  - Модели пользователей (`User`) с разделением ролей `parent` и `specialist` и расширенными полями профиля для специалистов (`organization`, `specialization`, `experience_years`).
  - Модель профиля ребёнка (`Child`), привязанная к аккаунту родителя/специалиста.
  - Модель результатов скрининга (`ScreeningResult`) с сохранением сырых событий (`raw_data`) для будущей аналитики и исследований, а также формированием отчётов под две роли.
- **Авторизация и безопасность (`auth.py`):**
  - Хеширование паролей (`passlib` / `bcrypt`) и выдача JWT-токенов (`python-jose`).
  - Проверка токена и получение текущего пользователя через `OAuth2PasswordBearer`.
- **Эндпоинты API (`main.py`):**
  - `POST /api/auth/register` — регистрация родителя или специалиста.
  - `POST /api/auth/login` — авторизация и получение `access_token`.
  - `GET /api/users/me` — получение данных текущего пользователя.
  - `POST /api/children` и `GET /api/children` — добавление и просмотр профилей детей.
  - `POST /api/screenings` — приём результатов тестирования, расчёт базовых метрик (скорость чтения WPM, понимание текста, ошибки) и возврат сводных данных родителю либо расширенных метрик специалисту.
- **Контейнеризация (`Dockerfile`, `docker-compose.yml`):**
  - Конфигурация для запуска FastAPI и PostgreSQL в Docker под дальнейший деплой на российскую инфраструктуру.

## Быстрый локальный запуск (без Docker)

1. Перейдите в папку бэкенда и активируйте виртуальное окружение:
   ```powershell
   cd backend
   .\.venv\Scripts\Activate.ps1
   ```
2. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```powershell
   uvicorn main:app --reload
   ```
4. Откройте интерактивную документацию Swagger UI:
   `http://127.0.0.1:8000/docs`
